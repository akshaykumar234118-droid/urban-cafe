URBAN CAFE WEBSITE
==================

Files:
- index.html: Home, featured menu, story and contact
- order.html: Separate ordering page, cart and checkout form
- style.css: Responsive styling
- app.js: Menu filtering, cart quantity/total and WhatsApp order handoff

HOW TO RUN:
1. Extract the ZIP.
2. Open index.html in a browser.
3. For a public website, upload all four files to a static host (Netlify, GitHub Pages, etc.).

IMPORTANT:
- The public listing found for Urban Cafe Restaurant is in Village Pamlahi, PO Thanedhar, Tehsil Kumarsain, Kotgarh, Himachal Pradesh 172030, phone +91 62300 13000.
- Menu items and prices are sample/demo content, not a verified official menu.
- Checkout is a demo. It sends order details to the cafe's WhatsApp number; it does not charge a card or process UPI. To accept real online payments, configure a payment provider (e.g. Razorpay) with merchant credentials and a secure backend. Never put secret keys in frontend JavaScript.
- Verify contact details, hours, menu and prices with the cafe before publishing.
